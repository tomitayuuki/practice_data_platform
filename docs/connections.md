# 接続先一覧

## 概要
本書は、本データ基盤へ取り込むデータの取得元（接続先）とその詳細情報を一覧化する。実装の進捗や接続先の変化に応じて、都度更新する管理用ドキュメントとする。

各接続先から実際に連携されるデータの技術仕様（取得方法・頻度・格納先等）は`docs/interfaces.md`（IF一覧）に記載する。1つの接続先から複数のIFが生まれる場合があるため、両ドキュメントは「接続先一覧＝1接続先1行」「IF一覧＝1IF1行」の粒度で分離している。
